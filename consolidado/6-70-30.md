Notebook que implementa a metodologia de validação cruzada **70/30** (70% treino, 30% teste) sobre os dados de exportação de cargas portuárias. ## Principais Aprendizados

### 1. Treino ≠ Teste
O erro de treino (R²) **não é confiável** para prever desempenho futuro. A métrica real é o **RMSE em dados não vistos** (teste).

### 2. R² é enganoso
Um R² alto em dados de treino pode mascarar:
- Overfitting (modelo memoriza padrões, não aprende)
- Heteroscedasticidade (variância não constante)
- Não-linearidade (relação linear é inadequada)

### 3. Transformações logarítmicas ajudam
- Reduzem violações de linearidade
- Melhoram homocedasticidade
- Aumentam interpretabilidade em termos de elasticidade

### 4. Breusch–Pagan detecta heteroscedasticidade
- Se p-valor < 0.05: reject H₀ (homocedasticidade)
- Transformação log pode corrigir o problema
- Importante para validar pressupostos de regressão linear

### 5. Limiares mudam decisões
Em regressão logística:
- Limiar 0.3: mais liberalista (mais verdadeiros positivos, mais falsos positivos)
- Limiar 0.5: equilibrado
- Limiar 0.7: mais conservador (menos falsos positivos, menos verdadeiros positivos)
- **Escolha depende do custo do erro** (negócio, não estatística)

### 6. Reprodutibilidade é crítica
- `set.seed()` garante resultados idênticos em futuras execuções
- Essencial para comunicação e auditoria
- Permite que colegas repliquem análises

### 7. RMSE é a métrica final
- MSE: erro quadrático médio (escala da resposta ao quadrado)
- RMSE: raiz do MSE (escala da resposta original)
- Comparável entre modelos: modelo com RMSE menor prediz melhor

## Código-Chave

### Divisão 70/30
```r
set.seed(1)  # Reprodutibilidade

itr <- sample(
  nrow(dados_reg),
  round(0.7 * nrow(dados_reg))
)

tr <- dados_reg[itr, ]   # 70% treino
te <- dados_reg[-itr, ]  # 30% teste
```

### Ajuste em Treino
```r
m1 <- lm(TOTAL_TONELADAS ~ TOTAL_TEU, data = tr)
m2 <- lm(TOTAL_TONELADAS ~ TOTAL_TEU + TOTAL_UNID, data = tr)
```

### Avaliação em Teste
```r
pred1 <- predict(m1, newdata = te)
pred2 <- predict(m2, newdata = te)

rmse1 <- sqrt(mean((te$TOTAL_TONELADAS - pred1)^2))
rmse2 <- sqrt(mean((te$TOTAL_TONELADAS - pred2)^2))
```
